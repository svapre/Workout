# Cross-AI Review Bundles

This folder is the shared entry point for external UI reviews.

Use:
- `plan-thorough/` for the plan-family review
- `ui-language/` for the cross-app naming / compact-mobile review

Each subfolder is AI-agnostic and contains:
- one generic prompt
- the docs relevant to that review scope
- the screenshots relevant to that review scope

Each subfolder is kept at 20 files so it can still be uploaded to tools with a 20-file limit.
