# Product Vision

## What This App Is
A personal training operating system.
Not a workout tracker. Not a generic fitness app.
A deterministic execution engine for structured transformation.

## Core Promise
The user never has to think during training. Only execute.

## What The App Does
- Executes pre-defined plans
- Tracks progress through stages and milestones
- Logs workout sessions with reflection data
- Exposes import/export for coach/AI feedback loop
- Operates fully offline, local-first

## What The App Does NOT Do
- Generate training recommendations
- Interpret user data and act on it autonomously
- Make training decisions
- Suggest workouts based on history
- Act as a recommendation engine of any kind

## The Three Modes
1. LIBRARY — build exercises and routines
2. PLANNING — structure the journey
3. EXECUTION — follow the plan

## The Feedback Loop
Execute → Log → Export → Coach/AI modifies → Import → Execute

## Target User
Anyone who wants structured, plan-driven training that is
set-and-go after the plan is created.

## Emotional Philosophy
Four moments that matter:
1. ARRIVAL — immediately know next action
2. START — frictionless commitment
3. EXECUTION — full focus, zero clutter
4. COMPLETION — satisfying, meaningful ceremony

## UI Philosophy
- Execution-first: next workout dominates, not menus
- Plan identity: theme colors/icons distinguish plans
- Emotional pacing: workout days = energy, rest days = calm
- One-glance state: stage + cycle + milestone + next action
- Mobile-first: natural during actual workouts
- No nav bar during execution mode
- Visual inspiration: Hevy, Strong, Lyfta (texture only)
  Functionally deeper than all of those apps.
